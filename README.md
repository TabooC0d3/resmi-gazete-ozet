# Resmi Gazete Ozet

T.C. Resmi Gazete'nin gunluk sayilarinin yapay zeka ile hazirlanan ozetleri. Ozetler hata icerebilir; esas olan Resmi Gazete'nin kendisidir: https://www.resmigazete.gov.tr
